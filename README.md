# my-website
我的個人網頁

## 職光 TOEIC Atlas

一個給繁體中文使用者的多益單字網站，致敬開源雅思單字專案 [詞光 Word Atlas](https://github.com/designfuchen/word-atlas)。

- **1,000 個多益必備單字**：依「衝 400／600／800／990 分必備單字」講義分成四段航程，每段 250 字，附中文釋義、職場例句與翻譯。
- **KK 音標與美英發音**：用台灣學生熟悉的 KK 音標，發音使用瀏覽器內建語音（美式／英式可切換）。
- **15 個職場場景**：辦公行政、人資職涯、財務金融、旅遊交通……可依場景、分數段、詞性與學習狀態篩選。
- **多益考點**：71 個常考字附上易混淆字、固定搭配與 Part 5 陷阱說明。
- **今日航程**：每天自動排好新詞與到期複習，用四段評分（忘了／模糊／記得／很簡單）安排下次複習時間。
- **五種練習**：Part 5 例句填空、看義選詞、看詞選義、聽音辨詞、拼字挑戰。
- **千詞星圖**：1,000 顆星依場景聚成星座，學會一個字就點亮一顆。
- **免註冊**：進度只存在瀏覽器的 localStorage，可匯出／還原備份。

### 本機預覽

純靜態網站，沒有建置步驟：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

也可以直接在 GitHub 的 Settings → Pages 選擇從 `main` 分支根目錄部署。

### 檔案

| 路徑 | 內容 |
| :--- | :--- |
| `index.html` | 頁面入口 |
| `assets/app.css` | 設計系統與版面 |
| `assets/app.js` | 路由、間隔複習、練習題、星圖 |
| `assets/words.js` | 1,000 個單字資料（`window.TOEIC_WORDS`） |

單字資料欄位：`w` 單字、`lv` 分數段、`t` 場景、`kk` KK 音標、`s` 詞性與釋義、`en`／`zh` 例句與翻譯、`f`／`a` 例句中出現的字形與位置（出填空題用）、`tip` 多益考點。
