# my-website
我的個人網頁

## 多益詞旅 TOEIC Voyage

給剛進職場、想進外商的人用的多益單字網站：英文基礎弱也沒關係，只要看得懂簡單英文就能開始。致敬開源雅思單字專案 [詞光 Word Atlas](https://github.com/designfuchen/word-atlas)。

### 核心原則

1. **全程用英文思考**：題目、提示、線索一律只用英文，沒有中文輔助模式，考試時不用在腦中翻譯。
2. **中文只在作答之後出現**：用小字放在英文解釋下面，用來確認意思，不能當答題線索。
3. **每一題都要先想出字義**：光靠刪去法、聽音比對拼字、看圖猜就能答對的題型都已移除（看圖選字、聽音辨詞）。
4. **改版不清掉進度**：舊的學習紀錄、收藏、造句本、闖關成績都保留，新欄位只會新增。

### 學習流程

- **3 分鐘程度測驗**：第一次使用先測，看單字選英文解釋（可按 I don't know）。答錯的猜測會扣分、I don't know 不扣分，較難的分數段分數不會高於較簡單的；結果顯示答對／答錯／不會各幾題，依結果從 400 或 600 段開始。測驗做到一半重新整理會接著做。
- **每天 10 個新字**（設定可調），一次 5–10 分鐘；**每天複習有上限**（預設 30 個），超過的往後排，畫面會寫「今天先複習最重要的 30 個」，先排頑固字和快忘的字。
- **翻面前先作答**：新字先看一張純英文詞卡，至少隔 4 張卡之後再考一次；答錯的字也至少隔 4 張卡才重出。學習中的回合會保存，重新整理後從同一張卡接著做。複習先出題（四個英文解釋選一個，或看解釋打出單字）。答錯直接記成「忘了」，答對才能選「記得」或「很簡單」（用了提示只能選「記得」）。
- **英文分層提示**：卡住時一層一層給：更簡單的英文換句話說 → 近義詞 → 挖空的例句（或拼字線索）。三層都看完還想不起來，可以看答案，記為答錯。
- **記憶聯想**：每個字都有字根拆解（super 上 + vis 看 → supervisor）與圖像聯想，只有真的難記的字才用中文諧音；詞卡上可以寫自己的聯想。
- **詞性家族與易混淆字**：employ／employee／employment 一起看；affect／effect、principal／principle 等 42 組易混淆字有對照說明與對照練習題。
- **頑固字**：在 3 個不同的日子答錯的字（同一天答錯多次只算一次）自動收進「頑固字」，用不同題型連續答對 3 次才畢業。
- **常用搭配**：每個字有一組先記的搭配（submit a report、reschedule the meeting），附簡單英文解釋，另有搭配選字題。

### 練習題型

例句填空（Part 5，每字 6 句輪替）、英英釋義、拼字、聽字選英文解釋、Part 2 聽問句選回應（122 題）、聽寫、常用搭配、易混淆字。聽力題美、英、澳口音輪流（美、英式單字為真人錄音，澳式與句子用裝置語音）。另有 50 關計時衝刺關卡與原創連載故事《NS-014 號航班》（Part 6 填空）。

### 職場應用

- **職場情境練習**：17 份外商常見的 Email、Teams 訊息和會議邀請，用學過的字填空。
- **外商面試專區**：三種自我介紹範本（應屆、轉職、一到三年經驗，可填入自己的資料）與 12 題常見英文面試題，回答裡放入本站單字，中文可逐段展開。
- **口說跟讀**：例句與面試回答都能先聽再跟讀，用瀏覽器內建語音辨識顯示聽到的內容與吻合度，只當參考。
- **職缺說明檢測器**：貼上一份英文職缺說明，標出已經會和還不會的字，一鍵把不會的字排到新字最前面。內容只在瀏覽器裡分析。

### 介面

介面以簡單英文為主；中文只出現在作答後的意思確認、詞卡上的中文釋義與例句翻譯、記憶聯想，以及面試與故事裡需要時才展開的翻譯。近義詞會標出能不能互換、差在哪裡，並用 1–5 個點表示一般英文裡有多常用，最常用的會標「Most used」。

### 讓進步看得見

詞彙推估多益分數（±50，僅供參考）、7 天與 30 天後的實際記住率、連續天數與補救卡（連續 7 天得 1 張，最多 2 張，可補回漏掉的一天）。

### 操作與效能

- **省電模式**：關掉開場動畫、紙張紋理、環境音、彩帶與換頁動畫。
- **通勤免持模式**：自動依序播放單字 → 英文解釋 → 例句，不播中文，支援耳機上的播放／下一首按鍵（依瀏覽器而定）。
- **首頁只放今天要做的事**；星圖、四段航程與 15 個職場場景移到「我的」。

### 本機預覽

純靜態網站，沒有建置步驟：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

### 檔案

| 路徑 | 內容 |
| :--- | :--- |
| `index.html` | 頁面入口 |
| `assets/app.css` | 設計系統與版面 |
| `assets/app.js` | 路由、間隔複習、題型與提示、程度測驗、職場工具、通勤模式、3D 星圖、音效 |
| `assets/words.js` | 1,000 個單字資料（`window.TOEIC_WORDS`） |
| `assets/extra.js` | 學習內容（`window.TOEIC_EXTRA`）：每字的簡單英文提示、字根、記憶聯想、詞性家族、常用搭配與解釋；易混淆字、Part 2 問答、職場文件、面試範本 |
| `assets/cloze.js` | 5,000 句額外的多益填空例句（`window.TOEIC_CLOZE`） |
| `assets/stories.js` | 航程故事章節（`window.TOEIC_STORIES`） |
| `assets/img/` | 插畫圖集 |
| `assets/audio/` | 美式／英式發音音訊精靈檔 |
| `assets/brand/` | 各頁插畫 |
| `assets/sound/` | 原創配樂、環境音與介面音效 |

單字資料欄位：`w` 單字、`lv` 分數段、`t` 場景、`kk` KK 音標、`d` 英英釋義（只用最常見的約 2,000 個英文字寫成）、`s` 詞性與中文釋義、`syn`／`ant` 近似詞與相反詞、`ex` 例句、`col` 常用搭配、`tip` 多益考點、`i` 插畫索引、`ar` 插畫狀態（`x` 表示插畫和字義連不起來，詞卡改顯示例句）、`u`／`k` 美式／英式錄音位置。
