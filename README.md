# my-website
我的個人網頁

## 多益詞旅 TOEIC Voyage

一個給繁體中文使用者的多益單字網站，致敬開源雅思單字專案 [詞光 Word Atlas](https://github.com/designfuchen/word-atlas)。

- **1,000 個多益必備單字**：依難度分成 400／600／800／990 四段航程，每段 250 字。
- **原創解說**：每個字都有分詞性釋義、近似詞、相反詞、日常例句、多益例句（附翻譯）與常用搭配，全部以台灣用語原創撰寫。
- **插畫、KK 音標與美英發音**：785 個字有專屬插畫，762 個字有美式與英式真人錄音（其餘使用瀏覽器內建語音），音標採台灣學生熟悉的 KK 音標。
- **15 個職場場景**：辦公行政、人資職涯、財務金融、旅遊交通……可依場景、分數段、詞性與學習狀態篩選。
- **多益考點**：71 個常考字附上易混淆字、固定搭配與 Part 5 陷阱說明。
- **今日航程**：每天自動排好新詞與到期複習，用四段評分（忘了／模糊／記得／很簡單）安排下次複習時間。
- **航程故事**：原創連載小說《NS-014 號航班》試讀五章，主角 Jun 在老旅行社上班第一天，印表機吐出一張 1996 年、寫著他名字的訂位。每章藏 9–10 個 400 分段單字（同章不放近義字），點字開詞卡、逐段或全章朗讀、中文可逐段展開；讀完用 Part 6 風格「故事填空」驗收。每日新詞依章節順序排，詞卡與翻面卡會附上該字在故事裡出現的那一句。
- **五種練習**：Part 5 例句填空、看義選詞、看詞選義、聽音辨詞、拼字挑戰。
- **環境音與音效**：原創合成的「夜航」配樂與機艙、海浪、雨聲三段無縫循環環境音，加上十種介面音效；唸單字時背景音自動降低。
- **3D 航道星系**：1,000 顆星排成旋臂星系，400／600／800／990 是由內到外的四條軌道，14 個職場場景各佔一條旋臂；可拖曳旋轉、滾輪或雙指縮放，學會一個字就點亮一顆（WebGL，不支援時自動改用 2D 星圖）。
- **開場星塵動畫**：每天第一次打開時，星塵聚成「多益詞旅」，點一下登機出發（可在護照頁關閉）。
- **絲滑轉場**：頁面依導覽方向滑動銜接，單字卡插畫直接飛成詞卡大圖，學習與練習換題時卡片滑入（View Transitions API，不支援時改用淡入）。
- **免註冊**：進度只存在瀏覽器的 localStorage，可匯出／還原備份。

### 本機預覽

純靜態網站，沒有建置步驟：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

也可以直接在 GitHub 的 Settings → Pages 選擇從 `main` 分支根目錄部署。

### 檔案

| 路徑 | 內容 |
| :--- | :--- |
| `index.html` | 頁面入口 |
| `assets/app.css` | 設計系統與版面 |
| `assets/app.js` | 路由、間隔複習、練習題、3D 星圖、開場動畫、轉場、音效引擎 |
| `assets/words.js` | 1,000 個單字資料（`window.TOEIC_WORDS`） |
| `assets/stories.js` | 航程故事章節（`window.TOEIC_STORIES`，`[[單字編號:字形]]` 標記章節目標字） |
| `assets/img/` | 插畫圖集（縮圖 8 張、大圖 32 張） |
| `assets/audio/` | 美式／英式發音音訊精靈檔 |
| `assets/brand/` | 首頁與各頁插畫 |
| `assets/sound/` | 原創配樂、環境音與介面音效 |

單字資料欄位：`w` 單字、`lv` 分數段、`t` 場景、`kk` KK 音標、`s` 詞性與釋義、`syn`／`ant` 近似詞與相反詞、`ex` 日常（`d`）與多益（`t`）例句（含翻譯，`f`／`a` 為例句中的字形與位置，供填空題使用）、`col` 常用搭配、`tip` 多益考點、`i` 插畫索引、`u`／`k` 美式／英式錄音在音訊檔中的位置。
